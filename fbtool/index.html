Kết nối Facebook

Cách 1 — Đăng nhập Facebook (khuyên dùng)

Bấm nút, đăng nhập trong cửa sổ của Facebook như bình thường. Lần sau mở trang, nếu trình duyệt vẫn đăng nhập Facebook thì tool tự kết nối.

Cài đặt App (App ID)
Cần cài đặt gì trong Facebook App?
  1. Settings → Basic → App Domains: thêm
  2. Facebook Login → Settings: bật Login with the JavaScript SDK, thêm vào Allowed Domains for the JavaScript SDK
  3. Tài khoản của bạn phải là Admin/Developer của App (không cần App Review khi dùng cho Page của chính mình)

Cách 2 — Dán Access Token (nhanh nhất)

Mở Graph API Explorer → Get User Access Token → tick các quyền:

🤖 Cài đặt AI — Gemini / Claude / Web trung gian

Chọn nhà cung cấp AI và dán API key để dùng nút "AI phân tích / viết trực tiếp". Muốn dùng web trung gian: chọn "Web trung gian (API riêng)" rồi điền Địa chỉ API, key và tên model.

Key chỉ lưu trên trình duyệt máy này.

Chưa kết nối.

Giữ đăng nhập lâu dài (tuỳ chọn, nên làm)

Token thường chỉ sống 1–2 giờ. Nhập App Secret của App (Settings → Basic) trước khi bấm Đăng nhập/Kết nối, tool sẽ đổi sang token ~60 ngày; token Page lấy từ đó không hết hạn. App Secret chỉ dùng một lần để đổi token, không được lưu ở đâu cả. Với Cách 2, token phải được tạo bằng chính App có App ID ở Cách 1.

Không muốn nhập App Secret? Dán token vào Access Token Debugger → bấm Extend Access Token → dán token mới vào Cách 2.

🔒 Phiên đăng nhập được lưu trên trình duyệt này (đóng tab vẫn còn) cho đến khi bạn bấm Thoát hoặc token hết hạn. Token chỉ gửi tới Facebook. Đừng dùng trên máy dùng chung.
